This entry answers the "One Word, One Username, One Reward" bounty with
exactly one word: the entrant's own make.fun username. No explanation, no
pitch, no padding — just the handle, exactly as the rules ask for it.

The handle is a doubled name: a digit followed by a syllable said twice.
It introduces itself and then says it again, so it lands in the mind the
way an echo does — easy to remember after a single glance, and the kind of
name its owner is happy to wear. A single word, written plainly and
confidently, is the whole entry.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` to `/output/entry.txt` (or to the directory
given by the `OUTPUT_DIR` environment variable). It is deterministic —
every run produces the exact same 9 bytes — and uses only the Node 22
standard library, with no network access.
